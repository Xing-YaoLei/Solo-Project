## 1. 产品概述

法律服务费用报价经营模拟游戏，面向法律服务岗位的训练场景，通过模拟真实的法律费用报价流程，帮助学员掌握金额校验、支付流水判断、对账差异分析和合同附件处理等核心技能。系统在金额不一致时给出原因分析，成绩写入训练记录，复盘可查看回款周期。

- 目标用户：法律服务岗位在职人员、新人培训学员
- 核心价值：降低实际工作中费用报价失误率，缩短培训周期

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 学员 | 管理员分配账号 | 参与训练、查看个人成绩与复盘 |
| 管理员 | 系统预设 | 配置题目/素材/奖励/开放时间/训练模式，查看全员训练记录 |

### 2.2 功能模块

1. **游戏主界面**：关卡选择、进度概览、新手引导入口
2. **金额校验识别**：对比报价单与合同金额，找出不一致项并选择原因
3. **支付流水选择**：从多条支付流水中选出与报价匹配的正确流程
4. **对账差异排序**：将多笔对账差异按严重程度排序
5. **合同附件处理**：为合同匹配正确附件，检查附件完整性
6. **配置管理页**：题目增删改、素材管理、奖励设置、开放时间控制、训练模式切换
7. **成绩与复盘**：训练记录列表、详情查看、回款周期分析图表
8. **新手引导**：围绕金额校验的交互式教学流程

## 3. 核心流程

学员登录后进入游戏主界面，按顺序解锁4大关卡。每个关卡内：读取任务描述 → 操作交互（校验/选择/排序/匹配）→ 提交结果 → 系统判定得分 → 不一致项给出原因分析 → 成绩写入记录 → 返回主界面解锁下一关。管理员在配置页维护所有题目与参数。

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深靛蓝 `#1B2A4A`（专业法律感）+ 琥珀金 `#D4A843`（高端商务感）
- 辅助色：石板灰 `#64748B`、翡翠绿 `#10B981`（成功提示）、珊瑚红 `#EF4444`（错误提示）
- 按钮风格：圆角矩形带轻微阴影，hover 时浮起加深阴影
- 字体：思源宋体/Source Han Serif 用于标题（法律文书感），思源黑体/Source Han Sans 用于正文
- 布局：深色侧边栏 + 浅灰内容区，卡片式模块布局
- 图标风格：线性图标，线条粗细2px，琥珀金描边

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 游戏主界面 | 关卡地图 | 深靛蓝背景，4个圆形关卡节点由路径线连接，节点内含图标与星级，琥珀金发光效果 |
| 游戏主界面 | 进度概览 | 顶部渐变进度条，琥珀金填充，数字百分比标签 |
| 金额校验识别 | 报价单展示 | 左侧白色卡片，表格式布局，行间交替底色，不一致行红色左边框 |
| 金额校验识别 | 原因选择 | 底部弹出面板，4列原因卡片，hover 放大，选中后琥珀金边框 |
| 支付流水选择 | 流水列表 | 垂直列表，每条流水一张卡片，金额数字加大加粗，选中态琥珀金底色 |
| 对账差异排序 | 差异卡片 | 可拖拽矩形卡片，左上角严重程度标签（红/橙/黄），拖拽时半透明+阴影 |
| 合同附件处理 | 合同展示 | 中央A4比例卡片，条款位置虚线框标注，拖入附件后实线+绿色对勾 |
| 配置管理页 | 题目管理 | 左侧分类Tab + 右侧表格，支持行内编辑，操作列含编辑/删除按钮 |
| 成绩与复盘 | 回款周期 | 渐变折线图+分组柱状图，Chart.js 风格，琥珀金高亮关键节点 |
| 新手引导 | 引导流程 | 半透明遮罩，高亮聚焦区域，对话气泡带箭头指向操作元素 |

### 4.3 响应式

- 桌面端优先（1920×1080 游戏区域）
- 平板端适配（1024×768 最小支持）
- 触屏优化：拖拽操作支持 touch 事件，卡片最小触控区域 44×44px

### 4.4 3D 场景指导

不适用，本项目为 2D 游戏。
