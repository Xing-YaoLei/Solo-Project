## 1. 产品概述

二手车门店车源上架趋势看板——面向二手车经销商老板及门店运营人员的数据分析看板，用于拆解和追踪门店车源上架全链路数据，帮助决策者快速掌握库存动态、检测质量、整备进度与试驾异常，提升库存周转效率。

- 核心目标：将检测仪、金融审批表、车源库三路数据统一呈现，消除数据孤岛，支撑早会口径一致化
- 目标用户：二手车门店老板、运营经理、检测主管、整备主管

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 门店老板 | 管理员分配账号 | 全部看板、筛选视图保存/分享、导出、权限管理 |
| 运营经理 | 管理员分配账号 | 全部看板、筛选视图保存、导出 |
| 检测/整备主管 | 管理员分配账号 | 对应模块看板、只读导出 |

### 2.2 功能模块

1. **看板主页**：最近刷新时间、全局筛选器、四大核心图表区域、筛选视图管理
2. **车辆档案趋势**：按日/周/月展示上架量趋势线，支持同环比对比
3. **检测报告构成**：检测通过/未通过/待检测的构成比例与明细下钻
4. **整备清单明细**：整备状态分布、平均整备周期、超期预警列表
5. **试驾记录异常标注**：试驾频次分布、异常标注（事故车试驾、超速试驾等）高亮
6. **筛选视图管理**：保存常用筛选组合为视图，早会一键切换
7. **分享与导出**：带权限分享链接、导出含库存周转口径的报表

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 看板主页 | 顶部状态栏 | 显示最近刷新时间（醒目位置，非设置内隐藏）、数据源状态指示灯 |
| 看板主页 | 全局筛选器 | 门店、日期范围、车源类型、品牌等筛选条件，支持保存为视图 |
| 看板主页 | 车辆档案趋势 | D3.js 折线/面积图，展示上架量趋势，hover 显示明细，点击下钻车源库 |
| 看板主页 | 检测报告构成 | D3.js 环形图+堆叠柱状图，展示检测通过率趋势与构成，下钻检测仪原始数据 |
| 看板主页 | 整备清单明细 | D3.js 横向条形图+表格，展示整备状态分布与超期预警，关联金融审批表 |
| 看板主页 | 试驾记录异常标注 | D3.js 散点图+日历热力图，标注异常试驾记录，下钻试驾详情 |
| 看板主页 | 筛选视图管理 | 侧边抽屉，保存/加载/删除筛选视图，设为默认视图 |
| 看板主页 | 分享与导出 | 生成带权限的分享链接，导出 PDF/Excel 含库存周转口径说明 |

## 3. 核心流程

用户打开看板 → 查看最近刷新时间确认数据时效 → 通过全局筛选器调整口径 → 在四大图表中浏览趋势与异常 → 保存筛选为视图供早会使用 → 分享/导出数据

```mermaid
    "D" --> "是" --> "E[加载筛选视图]"
    "D" --> "否" --> "F[手动设置筛选条件]"
    "E" --> "G[浏览四大图表]"
    "F" --> "G"

    "H" --> "是" --> "I[下钻明细数据]"
    "H" --> "否" --> "J{需要保存/分享?}"
    "I" --> "J"
    "J" --> "保存视图" --> "K[保存筛选为视图]"
    "J" --> "分享" --> "L[生成带权限分享链接]"
    "J" --> "导出" --> "M[导出含库存周转口径报表]"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深墨绿 (#0F2419) 为底色，搭配琥珀金 (#D4A843) 作为强调色，营造专业商务质感
- **辅助色**：石墨灰 (#2D3436)、象牙白 (#F8F9FA)、警示红 (#E74C3C)、安全绿 (#27AE60)
- **按钮风格**：圆角 6px，主按钮深墨绿底+琥珀金文字，次按钮描边风格
- **字体**：标题用 DM Serif Display，正文用 Noto Sans SC，数据用 JetBrains Mono
- **布局风格**：左侧窄导航栏 + 右侧内容区，卡片式模块布局，顶部全局筛选条
- **图标风格**：线性图标，统一 1.5px 描边，lucide-vue-next 图标库

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 看板主页 | 顶部状态栏 | 深墨绿背景，琥珀金刷新时间文字，数据源状态小圆点（绿/黄/红） |
| 看板主页 | 全局筛选器 | 白色卡片横条，下拉选择+日期范围+标签式已选条件，右侧保存视图按钮 |
| 看板主页 | 车辆档案趋势 | 深色卡片，D3.js 面积折线图，hover 浮层显示数据点详情 |
| 看板主页 | 检测报告构成 | 深色卡片，左侧环形图+右侧堆叠柱状图，点击扇区高亮联动 |
| 看板主页 | 整备清单明细 | 深色卡片，横向条形图+可滚动表格，超期行红色左边框 |
| 看板主页 | 试驾记录异常标注 | 深色卡片，散点图+日历热力图，异常点红色脉冲动画 |
| 看板主页 | 筛选视图管理 | 右侧抽屉面板，视图列表卡片，支持拖拽排序 |
| 看板主页 | 分享与导出 | 底部工具栏，分享按钮+导出下拉菜单，导出含口径说明页 |

### 4.3 响应式设计

- 桌面优先设计，1920px 为主视口
- 1440px 以下图表卡片从 2 列调整为单列堆叠
- 768px 以下隐藏左侧导航为汉堡菜单，筛选器折叠为图标按钮

### 4.4 动效设计

- 图表加载：staggered fade-in + draw 动画，面积图从左到右渐显
- 数据刷新：脉冲波纹效果从刷新时间向外扩散
- 异常标注：红色脉冲呼吸动画，吸引注意力
- 卡片 hover：微妙上移 + 阴影加深
- 筛选视图切换：图表区域平滑过渡动画
