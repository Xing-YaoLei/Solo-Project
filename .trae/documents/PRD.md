## 1. 产品概述

康复中心康复评估结算台——面向康复中心的综合评估管理与结算平台，解决评估量表配置分散、训练处方执行追踪困难、医保拒付处理无回溯等痛点。目标用户为康复中心管理员、治疗师和财务人员，核心价值在于将评估、训练、结算全流程数字化并闭环管理。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 管理员 | 系统分配 | 配置评估量表字典、训练处方规则、治疗日历阈值、用户管理 |
| 治疗师 | 管理员创建 | 填写评估记录、执行训练处方、管理器械状态、护理日志 |
| 财务人员 | 管理员创建 | 处理医保结算、拒付处理、补录/重试/关闭操作、财务报表 |

### 2.2 功能模块

1. **评估量表管理**：量表字典配置、量表项目维护、评估记录录入与查询
2. **训练处方中心**：处方规则配置、处方生成与执行追踪、训练完成率统计
3. **治疗日历**：日历阈值设置、排班与治疗计划、日历视图展示
4. **器械管理**：器械台账、状态监控、维护记录
5. **护理日志**：日志记录、日志查询、日志关联评估
6. **医保结算台**：结算单管理、拒付提醒推送、补录/重试/关闭操作、操作回看
7. **复盘分析**：训练完成率报表、多维组合查询、趋势分析

## 3. 核心流程

### 3.1 康复评估流程

治疗师选择患者和评估量表 → 系统加载量表项目 → 治疗师逐项填写评分 → 系统自动计算总分与等级 → 根据处方规则自动生成训练处方建议 → 治疗师确认或调整处方 → 处方进入执行队列 → 治疗日历自动排期

```mermaid
flowchart TD
    "选择患者与量表" --> "加载量表项目"
    "加载量表项目" --> "逐项评分"
    "逐项评分" --> "自动计算评分等级"
    "自动计算评分等级" --> "匹配处方规则"
    "匹配处方规则" --> "生成处方建议"
    "生成处方建议" --> "治疗师确认/调整"
    "治疗师确认/调整" --> "处方入队执行"
    "处方入队执行" --> "日历自动排期"
```

### 3.2 医保拒付处理流程

结算单提交医保 → 医保返回拒付 → 系统推送提醒至负责人 → 负责人查看拒付原因 → 选择操作：补录材料重试 / 直接重试 / 关闭 → 操作记录写入时间线 → 状态更新

```mermaid
flowchart TD
    "提交医保结算" --> "医保返回结果"
    "医保返回结果" -->|"拒付"| "系统推送提醒"
    "系统推送提醒" --> "负责人查看拒付原因"
    "负责人查看拒付原因" --> "选择处理方式"
    "选择处理方式" -->|"补录材料"| "上传补充材料"
    "选择处理方式" -->|"重试提交"| "重新提交结算"
    "选择处理方式" -->|"关闭"| "标记关闭并记录原因"
    "上传补充材料" --> "重新提交结算"
    "重新提交结算" --> "更新结算状态"
    "标记关闭并记录原因" --> "更新结算状态"
```

### 3.3 训练完成率复盘流程

选择复盘时段与范围 → 系统汇总训练数据 → 计算各维度完成率 → 生成趋势报表 → 标注异常节点 → 支持下钻至单条记录

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深靛蓝(#1B2A4A)搭配翡翠绿(#2DD4A8)强调色，传达专业与康复活力
- **辅助色**：暖灰(#F5F3EF)背景、琥珀橙(#F59E0B)告警、珊瑚红(#EF4444)错误/拒付
- **按钮风格**：圆角8px，主按钮实心填充，次按钮描边，操作按钮带图标
- **字体**：中文使用思源黑体(Noto Sans SC)，数字/英文使用 DM Sans，正文14px/行高1.6
- **布局风格**：左侧固定导航栏(240px)，右侧内容区，卡片式模块布局
- **图标**：线性图标风格(Phosphor Icons)，2px描边，统一20px尺寸

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 仪表盘 | 概览卡片 | 四宫格统计卡，翡翠绿渐变背景，数字使用 DM Sans Bold 32px |
| 仪表盘 | 快捷操作 | 圆形图标按钮组，hover时弹性缩放动画 |
| 评估量表列表 | 量表表格 | 斑马纹表格，状态标签彩色胶囊，顶部搜索与筛选栏 |
| 新建评估 | 评估表单 | 分步表单(Stepper)，进度指示条，实时评分预览面板 |
| 训练处方执行 | 处方追踪 | 时间轴视图，状态节点彩色圆点，进度条渐变填充 |
| 治疗日历 | 日历视图 | 月历网格，治疗时段色块，冲突项红色边框闪烁 |
| 医保结算台 | 拒付处理 | 卡片式拒付列表，操作按钮组，内嵌操作时间线 |
| 复盘分析 | 趋势报表 | SVG折线图/柱状图，悬浮提示卡，筛选器侧边栏 |

### 4.3 响应式策略

- 桌面优先设计(1440px基准)
- 1024px以下：导航栏折叠为图标模式
- 768px以下：侧边栏收起为底部导航，卡片单列排列
- 触控优化：按钮最小44px点击区域，表单输入框增大

### 4.4 动效设计

- 页面切换：Hotwire Turbo Drive 过渡，fade+slide 200ms
- 卡片加载：stagger入场动画，每张延迟50ms
- 状态变更：数字滚动动画(countup)，进度条弹性填充
- 拒付提醒：顶部滑入通知条，5秒自动消失
- 日历项拖拽：Hotwire Stimulus 拖拽排序，ghost占位
