# 法律服务案件委托风险监测平台

> Legal Case Entrustment Risk Monitor Dashboard

基于 **Python Dash + Plotly + Pandas + PostgreSQL + Celery** 构建的法律服务案件委托数据监测与可视化系统，为律所/法务团队提供客户档案趋势、案件阶段构成、证据附件明细、庭审日程异常标注四大核心监测图表。

## ⚙️ 核心功能特性

### 📊 四大核心图表

| 图表 | 说明 | 特点 |
|------|------|------|
| **客户档案趋势** | 客户新增/累计趋势 | 双轴(柱状+折线堆叠)、按客户类型分组 |
| **案件阶段构成** | 当前9个阶段的案件分布 | 左:阶段柱状图 右:环形占比+中心总计 |
| **证据附件明细** | 全量证据状态追踪表 | 按状态着色、关联案件/文件信息 |
| **庭审日程异常** | 时间轴视图+风险标注 | 正常/低危/中危/高危四级色点区分 |

### 🔐 六角色权限体系 (RBAC)

| 角色 | 数据范围 | 导出 | 分享 | 财务 | 说明 |
|------|---------|------|------|------|------|
| `admin` | 全所全部 | ✅ | ✅ | ✅ | 系统管理员 |
| `partner` | 本部门 | ✅ | ✅ | ✅ | 合伙人/部门主任 |
| `lawyer` | 本人主办 | ✅ | ✅ | ❌ | 主办律师 |
| `paralegal` | 本团队 | ❌ | ❌ | ❌ | 律师助理 |
| `client` | 本人委托 | ✅ | ❌ | ✅ | 客户(分享视图) |
| `auditor` | 全所只读 | ✅ | ❌ | ✅ | 风控/审计 |

### 🔗 分享链接系统

- 基于 **SHA-256 Token** 生成唯一分享链接
- 支持 **角色范围**：客户视角/律师视角/审计视角
- 支持 **有效期**：1小时/24小时/72小时/7天（默认72h）
- 支持 **限定内容**：是否含财务数据、是否限定单案
- 支持 **访问控制**：可设置最大查看次数、随时可撤销
- **访问记录**：记录访客IP/UA/时间

### 📥 数据接入三源

1. **邮件附件**：IMAP自动拉取未读邮件→OCR解析→自动匹配案号→归类为证据
2. **日历同步**：ICS URL/WebDAV订阅→自动识别庭审关键词→排期入库
3. **收款流水**：银行对账单/支付宝/微信CSV→智能匹配合同/客户→更新收款状态

### 🚨 庭审异常检测引擎

检测维度（自动入库并标注）：
- ⏰ **临近开庭**：≤7天 → 低/中/高危
- 📋 **临近未准备**：≤72h且关键材料未就绪 → 高危
- 🔀 **律师时间冲突**：同一律师两案时间重叠 → 高危
- 📝 **已改期**：状态标为已改期 → 中危
- ⚠️ **已过未完成**：庭审时间已过未标记完成 → 中危
- 👨‍⚖️ **审判人员集中排期**：同法官4小时内多案

### 📤 导出功能（含案件进展口径）

导出的Excel文件包含 **10张工作表**，其中 **"数据口径说明"** 页详细标注：

```
├─ 数据口径说明     ← 4类状态的官方定义 + 数据来源 + 更新时间
├─ 客户档案趋势     ← 按月/客户类型统计
├─ 案件阶段构成     ← 9阶段分布+占比
├─ 证据附件明细     ← 9项核心字段
├─ 庭审日程异常     ← 异常类型+紧急程度
├─ 案件总览         ← 全部基础信息
├─ 收款汇总         ← (有权限时) 回款率/差额
├─ 导出信息         ← 导出人/角色/范围/时间/保密提示
└─ ...
```

## 🚀 快速启动

### 环境要求

| 组件 | 推荐版本 | 用途 |
|------|---------|------|
| Python | 3.10+ | 主运行时 |
| PostgreSQL | 14+ | 业务数据存储 |
| Redis | 6+ | Celery Broker/Backend |

### 步骤1：安装依赖

```bash
cd MP0453
python3 -m venv .venv
source .venv/bin/activate    # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### 步骤2：配置环境变量

```bash
cp .env.sample .env
# 编辑 .env:
#   - 修改 SECRET_KEY
#   - 配置 DATABASE_URL（PostgreSQL连接串）
#   - 配置 CELERY_BROKER_URL（Redis连接串）
#   - 配置邮箱/日历同步凭据
```

> 💡 **快速试用（无PG/Redis亦可）**：
> 系统内置 **SQLite fallback** 支持，无需修改配置，首次启动会自动创建内存库并载入演示数据。

### 步骤3：启动Dash Web服务

```bash
python3 run.py
```

启动后访问：**http://localhost:8050**

### 步骤4（可选）：启动Celery调度服务（需要Redis）

```bash
# Worker + Beat（合并启动，开发用）
celery -A celery_app worker -B -l INFO -P solo

# 生产环境分开启动：
celery -A celery_app worker -l INFO -c 4       # 任务执行器
celery -A celery_app beat -l INFO               # 周期调度器
```

**默认调度频率**（[config.py](file:///Users/yaoleyxing/Developer/solo-mange-pro/MP0453/config.py#L37-L60) 可改）：

| 任务 | 频率 | 说明 |
|------|------|------|
| 邮件附件同步 | 每 30 分钟 | 拉取未读邮件并解析 |
| 日历同步 | 每 1 小时 | 同步庭审排期 |
| 收款流水导入 | 每 2 小时 | 扫描data目录 |
| 庭审异常检测 | 每 15 分钟 | 重新计算异常标注 |
| 物化视图刷新 | 每 10 分钟 | 预热Dashboard数据 |

## 🎯 核心设计亮点

1. **刷新时间徽章**：每个图表右上角实时显示最近刷新时间（带脉冲动画小圆点）
2. **角色即视图**：无需额外权限配置，6角色打开即见不同KPI和图表数据
3. **分享链接即身份**：通过 VirtualUser 类实现访客身份，复用同一套权限模型
4. **口径即契约**：导出Excel自带口径页，避免跨部门对数据定义歧义
5. **三源对账**：邮件/日历/收款三源独立入库，案件主表关联汇总
6. **异常持续检测**：15分钟一轮的异常扫描覆盖5种风险场景

## 🛠️ 常见问题

| 问题 | 解决 |
|------|------|
| 启动报错 `No module named 'psycopg2'` | `pip install psycopg2-binary`，或直接用SQLite模式 |
| Celery启动报错 `Redis cannot connect` | 先启动本地Redis：`redis-server`，或跳过Celery仅用Web |
| 分享链接打开是登录页 | 检查链接中是否包含 `/share/` 路径，不要直接访问 `/dashboard/` |
| 中文显示为方框 | 服务器需安装中文字体（思源黑体/微软雅黑），本地Mac/Win通常正常 |
