## 1. 产品概述

景区运营游客投诉协同台——面向景区运营团队的一站式投诉数据沉淀与协同处理平台，解决投诉流转不透明、处理超时无人兜底、角色权限混乱等痛点，目标用户为景区运营管理者及一线服务人员。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 游客 | 扫码自助投诉 | 提交投诉、查看自身工单、补充材料 |
| 票务员 | 管理员分配账号 | 受理票务类投诉、查看票务相关字段 |
| 巡场员 | 管理员分配账号 | 受理现场类投诉、上传现场证据 |
| 运营 | 管理员分配账号 | 全量投诉查看、分派/驳回/升级、导出报表、配置敏感字段可见性 |

### 2.2 功能模块

1. **投诉工单台**：问题标签、证据附件、处理时限、状态流转
2. **协同侧栏**：升级记录配置、回访结果留痕、常用筛选
3. **报表中心**：按关闭时长/日期/负责人下钻的统计分析
4. **待办池**：超时工单自动入池、补充材料、驳回重提、重新分派
5. **权限管理**：角色敏感字段脱敏、导出权限、处理入口分角色配置

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 登录页 | 认证表单 | Lucia Auth 驱动的用户名密码登录，角色自动识别 |
| 投诉工单台 | 工单列表 | 分页展示投诉工单，支持按标签/状态/时限/负责人筛选 |
| 投诉工单台 | 工单详情操作区 | 问题标签选择、证据附件上传/预览、处理时限倒计时 |
| 投诉工单台 | 协同侧栏 | 升级记录时间线、回访结果表单、常用筛选快捷标签 |
| 投诉工单台 | 流转操作栏 | 补充材料、驳回重提、重新分派、关闭工单 |

## 3. 核心流程

游客扫码提交投诉 → 系统自动打标签并分派至对应角色 → 票务员/巡场员受理处理 → 超时未处理自动进入待办池 → 运营介入升级/驳回/重分派 → 处理完成回访留痕 → 关闭工单纳入报表统计

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深青绿(#0D7377) + 琥珀警示色(#E8A838) + 中性灰底(#F4F5F7)
- **按钮风格**：圆角8px，主操作实心填充，次操作描边
- **字体**：标题使用 Noto Serif SC，正文使用 Noto Sans SC，数据使用 JetBrains Mono
- **布局风格**：左侧导航 + 主内容区 + 右侧协同栏三栏布局
- **图标风格**：线性描边图标(Phosphor Icons)

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 登录页 | 认证表单 | 居中卡片式表单，景区品牌Logo，角色色带指示 |
| 投诉工单台 | 工单列表 | 表格布局，行高宽松，状态色标，时限倒计时标签 |
| 投诉工单台 | 工单详情操作区 | 标签多选芯片、附件缩略网格、时限进度条 |
| 投诉工单台 | 协同侧栏 | 时间线组件、折叠表单、筛选标签组 |
| 投诉工单台 | 流转操作栏 | 底部固定操作栏，按钮带图标+文字 |
| 待办池 | 超时待办列表 | 卡片式列表，紧急度红色渐变边框，认领动效 |
| 待办池 | 待办操作 | 悬浮操作菜单，批量勾选复选框 |
| 报表中心 | 统计看板 | 图表卡片网格，下钻面包屑导航 |
| 报表中心 | 导出功能 | 导出按钮带权限锁图标，字段脱敏预览 |
| 权限管理 | 角色配置 | 角色卡片拖拽排序，权限开关矩阵 |

### 4.3 响应式策略

- 桌面优先设计，1920px 基准
- 中等屏幕(≤1280px)：协同侧栏折叠为抽屉
- 小屏幕(≤768px)：单栏布局，底部Tab导航
- 触摸优化：按钮最小44px点击区域，滑动手势切换Tab
