# 景区门票预约经营模拟培训游戏

基于 Cocos Creator 3.x + TypeScript + Tiled 开发的景区运营培训游戏，帮助新人快速掌握门票预约审核、冲突检测、改约处理等核心业务技能。

## 功能特性

### 游戏模式
- **正式训练**：系统性岗位培训，循序渐进的关卡设计
- **自由练习**：无压力练习模式，适合新手熟悉操作
- **挑战模式**：高难度时段冲突挑战，考验快速判断能力

### 岗位类型
- **检票员**：基础预约审核，识别简单冲突
- **预约专员**：多景点多时段预约管理
- **现场经理**：综合复杂场景处理

### 核心玩法
- **冲突检测**：识别黑名单、容量超限、时段重叠、重复预约等冲突
- **改约处理**：为冲突预约推荐最佳改约时段
- **到场判断**：根据游客到场状态进行入园审核
- **计分系统**：连击奖励、快速判定奖励、错误扣分

### 新手引导
- 首次进入自动触发引导教程
- 围绕冲突检测展开，直观易懂
- 分步讲解界面功能和操作方法

### 结算系统
- 通关展示得分、用时、正确率
- 详细错因分析，帮助学习改进
- 星级评价系统，记录最佳成绩

## 核心玩法说明

### 冲突类型
| 冲突类型 | 说明 | 推荐操作 |
|---------|------|---------|
| 无冲突 | 预约正常 | 批准 |
| 黑名单 | 游客在黑名单中 | 拒绝 |
| 容量超限 | 时段预约人数达上限 | 改约 |
| 时段重叠 | 同一游客同时段重复预约 | 改约/拒绝 |
| 重复预约 | 同一身份证多次预约 | 拒绝 |

### 操作说明
1. 从左侧预约列表中选择待处理任务
2. 查看预约详情，识别冲突类型
3. 根据情况选择操作：
   - **批准**：无冲突的正常预约
   - **拒绝**：黑名单等不可调和的冲突
   - **改约**：容量不足等可改约情况
4. 完成所有任务或时间耗尽后结算

### 计分规则
- 正确操作：+100 分
- 错误操作：-50 分
- 连击奖励：每连击 +10 分（最高 +50）
- 快速判定：30秒内完成 +20 分
- 星级评价：根据得分、正确率、用时综合评定

## 开发指南

### 环境要求
- Cocos Creator 3.8 或更高版本
- Node.js 16+（用于构建工具）

### 项目运行
1. 使用 Cocos Creator 打开项目
2. 设置 `assets/scenes/MainMenu.scene` 为启动场景
3. 点击预览按钮运行游戏

### 扩展开发
- 添加新关卡：在 `LevelDataConfig.ts` 中新增关卡配置
- 添加新冲突类型：在 `GameEnums.ts` 和 `ConflictDetector.ts` 中扩展
- 添加新岗位：在 `GameEnums.ts` 中定义，配置对应关卡

## 核心类说明

### GameManager
游戏全局管理器，单例模式，负责：
- 关卡初始化和进度管理
- 预约处理和状态更新
- 游戏时间和暂停控制
- 游戏结果计算

### ConflictDetector
冲突检测核心类，提供：
- 全量冲突检测 `detectAllConflicts()`
- 单项冲突检测方法
- 冲突描述文本获取
- 推荐操作判断

### ScoreSystem
计分系统，负责：
- 操作正确性判定
- 分数计算和连击统计
- 星级评价计算
- 错误记录和错因分析
