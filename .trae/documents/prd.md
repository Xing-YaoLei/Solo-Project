## 1. 产品概述

养老护理床位排班风险监测图——将床位排班从静态报表中拆出，构建动态风险监测看板，实时标注护理终端延迟、门禁记录缺失、收费系统口径变化等异常，支持复盘备注、跌倒时间标记和护理达标计算规则导出。

- 目标用户：养老院护理主管、运营管理员、质控人员
- 核心价值：将排班风险可视化，减少因数据延迟、记录缺失和口径变化导致的误判，提升护理质量与运营透明度

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 护理主管 | 管理员分配账号 | 查看看板、添加复盘备注、导出报告、管理排班 |
| 运营管理员 | 管理员分配账号 | 查看看板、导出报告、查看收费口径变化 |
| 质控人员 | 管理员分配账号 | 查看看板、添加复盘备注、导出报告 |

### 2.2 功能模块

1. **风险监测看板页**：排班趋势图、风险标注（终端延迟/门禁缺失/口径变化）、跌倒时间标记、实时刷新
2. **用药清单视图**：老人用药时间线、服药状态、异常提醒
3. **探访记录视图**：探访时间线、门禁关联、记录缺失标注
4. **活动签到视图**：活动排期、签到状态、异常标记
5. **复盘备注面板**：异常点旁直接添加/查看复盘备注
6. **数据导出**：下载含护理达标计算规则的报告

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|

## 3. 核心流程

### 3.1 风险监测看板主流程

用户打开看板 → 自动加载排班数据与风险标注 → 发现异常点 → 点击异常点添加复盘备注 → 跌倒事件自动标记时间 → 导出含达标规则的报告

```mermaid
flowchart TD
    "A[用户打开风险监测看板]" --> "B[加载排班数据与风险标注]"
    "B" --> "C{是否存在异常?}"
    "C" --> "|是| D[异常点高亮显示]"
    "C" --> "|否| E[正常趋势展示]"
    "D" --> "F[点击异常点]"
    "F" --> "G[添加复盘备注]"
    "D" --> "H[跌倒时间标记]"
    "H" --> "I[保留时间标记在趋势图]"
    "G" --> "J[选择导出]"
    "I" --> "J"
    "E" --> "J"
    "J" --> "K[下载含达标规则的报告]"
```

### 3.2 数据刷新与标注流程

```mermaid
flowchart TD
    "A[看板定时刷新]" --> "B[拉取最新数据]"
    "B" --> "C[检测护理终端延迟]"
    "B" --> "D[检测门禁记录缺失]"
    "B" --> "E[检测收费口径变化]"
    "C" --> "|存在延迟| F[图表标注延迟时间戳]"
    "D" --> "|存在缺失| G[缺失时段高亮]"
    "E" --> "|存在变化| H[口径变更标记]"
    "F" --> "I[更新风险监测图]"
    "G" --> "I"
    "H" --> "I"
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深靛蓝 `#1B2A4A`（沉稳专业），辅助色：琥珀橙 `#F59E0B`（风险警示）、翡翠绿 `#10B981`（正常/达标）、珊瑚红 `#EF4444`（异常/紧急）
- 按钮风格：圆角微阴影，警示按钮带脉冲动画
- 字体：标题使用 Noto Serif SC（中文衬线），数据使用 JetBrains Mono（等宽），正文使用 Noto Sans SC
- 布局风格：左侧导航 + 右侧看板区域，顶部状态栏，卡片式模块布局
- 图标风格：线性图标，统一 2px 描边

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 风险监测看板 | 排班趋势图 | 深色背景折线图，异常点脉冲标记，时间标记虚线 |
| 风险监测看板 | 风险标注层 | 图表上方浮动标签，延迟显示时间戳，缺失显示红色区间 |
| 风险监测看板 | 复盘备注 | 异常点旁弹出面板，半透明背景，备注列表 |
| 用药清单 | 用药时间线 | 水平时间轴，药物节点图标，异常红色标记 |
| 探访记录 | 探访时间线 | 垂直时间轴，探访卡片，缺失区间灰色遮罩 |
| 活动签到 | 签到状态 | 活动卡片网格，签到状态色块 |
| 数据导出 | 导出面板 | 模态对话框，时间选择器，格式选择，规则附件预览 |

### 4.3 响应式

- 桌面优先设计，最小宽度 1280px
- 看板图表区域自适应宽度
- 侧边导航在小屏可折叠
