# 即时下单漏斗报表看板

本地跑腿即时下单漏斗报表系统，用于把即时下单从静态报表中拆出来，支持订单全链路分析、异常监测、复盘备注和赔付成本计算。

## 技术栈

- **Python Dash** - 交互式数据可视化看板
- **Plotly** - 图表渲染（漏斗图、地图、趋势图等）
- **Pandas** - 数据处理和分析
- **PostgreSQL** - 数据持久化存储
- **Celery + Redis** - 异步任务处理（数据同步、异常检测、赔付计算）

## 功能模块

### 1. 漏斗分析 (`funnel`)
- 10 阶段即时下单转化漏斗（下单 → 支付 → 派单 → 接单 → 取货 → 配送 → 送达 → 完成）
- 各阶段转化率、平均耗时、流失原因分布
- 关键指标：总订单数、已完成数、整体转化率、系统延迟、支付缺失、拒单率

### 2. 订单地址 (`orders`)
- 订单地址地图分布（取货点/送货点）
- 多维度筛选：订单状态、支付状态、地图接口版本
- 订单统计：金额、补贴、赔付、平均距离
- 订单详情弹窗（含赔付计算明细、复盘备注）

### 3. 骑手轨迹 (`tracks`)
- 骑手轨迹地图可视化（支持按骑手/订单筛选）
- 异常点高亮显示（偏离、停留、速度异常）
- 轨迹统计：点数、异常数、平均速度、时长
- **轨迹异常点备注功能**：点击轨迹点可添加判断备注（定位漂移/骑手停留/路线偏离/信号异常/正常波动/待确认），复盘时可看到当时判断

### 4. 补贴规则 (`subsidy`)
- 补贴规则列表：新用户、远距离、高峰时段、恶劣天气、夜间配送
- 补贴金额分布图
- **赔付成本计算规则说明**：基础赔付 + 距离赔付 + 高峰时段系数 + 异常补偿
- 补贴订单明细

### 5. 异常监测 (`anomaly`)
看板刷新时自动标出以下异常：

| 异常类型 | 检测逻辑 | 严重程度 |
|---------|---------|---------|
| **系统延迟** | 订单系统延迟 > 5 分钟 | 高/中 |
| **支付流水缺失** | 订单创建 2 小时后仍未完成支付 | 高 |
| **地图口径变化** | 不同地图版本间距离均值变化 > 10% | 中 |
| **骑手拒单趋势** | 连续时段拒单率超出基线 +15% | 高 |

- **拒单趋势图高亮受影响区间**：红色矩形标出异常时段
- 异常类型筛选、处理状态筛选
- 异常详情弹窗与处理

### 6. 复盘备注 (`review`)
- 复盘备注时间线（显示作者、类型、判断标签、时间）
- 判断标签：系统问题/骑手问题/用户问题/外部因素/综合因素
- 新增备注：关联订单、备注类型、判断标签、内容
- 历史备注列表

## 赔付成本计算规则

下载 Excel 报表时附带赔付规则说明 Sheet 和计算明细 Sheet。

### 计算公式

```
总赔付 = (基础赔付 + 距离赔付) × 高峰系数 + 异常补偿
```

| 项目 | 规则 |
|-----|------|
| 基础赔付 | ¥8.0/单 |
| 距离赔付 | 订单距离 × ¥2.0/km |
| 高峰系数 | 11-13 点、17-19 点 × 1.3 |
| 系统延迟补偿 | 延迟 > 5 分钟，额外 +¥3.0 |
| 支付流水缺失补偿 | +¥2.0 |
| 骑手拒单赔付 | 拒单次数 × ¥5.0/次 |
| 地图口径变化调整 | +¥1.5 |

```

├── .env.example            # 环境变量示例

    ├── __init__.py
    ├── sync_tasks.py       # 数据同步任务（订单/骑手/轨迹）
    ├── anomaly_tasks.py    # 异常检测任务（4 类异常）
    ├── compensation_tasks.py # 赔付计算任务
    └── data_tasks.py       # 数据查询/导出/备注任务
```

### 数据库表

| 表名 | 说明 |
|-----|------|
| `orders` | 订单主表（含漏斗阶段时间戳、延迟、拒单、地图版本等） |
| `riders` | 骑手表 |
| `rider_tracks` | 骑手轨迹点（含异常标记和备注关联） |
| `subsidy_rules` | 补贴规则 |
| `funnel_events` | 漏斗事件明细 |
| `anomalies` | 异常记录（含影响区间、赔付金额） |
| `review_notes` | 复盘备注 |
| `track_anomaly_notes` | 轨迹异常点备注 |
| `saved_views` | 保存的常用视图 |

## 快速开始

### 1. 环境准备

确保已安装：
- Python 3.9+
- PostgreSQL 12+
- Redis 6+

### 2. 安装依赖

```bash
./run.sh install
```

### 3. 配置环境变量

```bash
cp .env.example .env
# 编辑 .env 填入实际的 DB 和 Redis 连接信息
```

### 4. 初始化数据库

```bash
./run.sh init-db
```

### 5. 生成模拟数据

```bash
./run.sh seed-data
```

该命令会：
- 创建 50 个测试骑手
- 生成 30 天 500 条即时订单（含漏斗事件）
- 同步骑手轨迹
- 自动检测异常
- 批量计算赔付金额

### 6. 启动服务

方式一：分别启动（推荐用于调试）
```bash
# 终端 1: 启动 Celery Worker
./run.sh worker

# 终端 2: 启动 Dash Web
./run.sh web
```

方式二：一键启动
```bash
./run.sh all
```

### 7. 访问看板

打开浏览器访问：http://localhost:8050

## 数据下载

点击右上角「操作」→「导出报表」，下载的 Excel 包含以下 Sheet：

1. **订单明细** - 订单全字段数据
2. **漏斗分析** - 各阶段订单数、平均耗时、流失数
3. **异常记录** - 检测到的所有异常
4. **赔付规则** - 赔付成本计算规则说明
5. **赔付计算明细** - 每笔订单的赔付金额和计算公式
6. **补贴规则** - 所有补贴规则配置

## 常用视图保存

- 点击右上角「操作」→「保存当前视图」
- 输入视图名称，选择类型（漏斗/订单/轨迹/补贴）
- 保存的视图可快速切换恢复筛选条件
