# 养老护理康复活动漏斗报表

基于 Streamlit、Polars、DuckDB 和 MinIO 构建的养老护理康复活动数据看板。

## 功能特性

### 📊 核心功能
- **康复活动漏斗分析**：从活动计划到护理达标，全流程漏斗分析
- **异常自动检测**：
  - ⏰ 护理终端延迟
  - 💰 收费系统缺失
  - 📡 健康设备口径变化
  - 🚨 跌倒影响趋势

### 📈 常用视图
1. **活动签到视图** - 签到趋势、准时率、延迟分析
2. **风险事件视图** - 跌倒、压疮等风险事件统计与分析
3. **老人档案视图** - 老人健康状况、护理等级、活动记录

### 🔔 智能提醒
- 护理达标率低于阈值自动生成备注任务
- 跌倒事件影响期自动在趋势图中标注
- 复盘说明与异常点不分开，处理结论留在图表旁边

### 📥 数据导出
- 一键下载 Excel 报表
- 自动附带护理达标计算规则说明

## 技术栈

| 技术 | 用途 |
|------|------|
| **Streamlit** | 前端交互式看板 |
| **Polars** | 高性能数据处理 |
| **DuckDB** | 嵌入式分析数据库 |
| **MinIO** | 对象存储服务 |
| **Plotly** | 交互式图表可视化 |

## 快速开始

### 1. 环境准备

```bash
# 创建虚拟环境
python3 -m venv .venv
source .venv/bin/activate

# 安装依赖
pip install -r requirements.txt
```

### 2. 配置环境变量

复制 `.env.example` 为 `.env` 并根据需要修改：

```bash
cp .env.example .env
```

### 3. 启动应用

```bash
streamlit run app.py
```

应用将在 `http://localhost:8501` 启动。

### 4. 初始化数据

首次启动时，系统会自动生成示例数据（15位老人，30天的康复活动记录）用于演示。

在侧边栏可以：
- 重新生成示例数据
- 清除所有数据
- 调整达标阈值、跌倒影响天数等参数

## 核心功能说明

### 护理达标计算规则

达标率 = (达标活动次数 / 应完成活动总次数) × 100%

**权重分配**：
- 康复活动参与率：40%
- 护理操作规范率：30%
- 健康监测完成率：20%
- 风险事件发生率：10%

**阈值说明**：
- 优秀：≥ 95%
- 良好：85% - 94%
- 合格：70% - 84%
- 待改进：< 70%

### 异常检测规则

1. **护理终端延迟**：签到延迟超过24小时
2. **收费系统缺失**：已完成活动缺少收费系统记录
3. **健康设备口径变化**：日签到量波动>30%或平均延迟波动>50%
4. **跌倒影响趋势**：老人跌倒后7天内的康复活动受影响

### 备注任务生成

当老人护理达标率连续低于阈值（默认85%）且活动数≥3时，自动生成备注任务，包括：
- 任务创建时间和截止时间
- 达标率与阈值对比
- 处理人、处理状态、处理结论
