## 1. 产品概述

物业园区招商租户协同台是为产业园区、商业综合体量身定制的综合运营管理平台。面向园区管理层、巡检员、维修人员、财务人员和租户五类角色，解决巡检调度分散、合同水电核对繁琐、工单超时失控、审批追溯困难等核心痛点，实现从招商入驻到日常运营的全流程数字化协同。

- **目标用户**：园区物业运营团队及入驻租户
- **核心价值**：一屏掌控园区运营全貌，工单超时自动预警，角色待办精准分发，审批追溯全程留痕

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 园区管理员 | 后台分配 | 全模块访问、审批决策、趋势看板、角色管理 |
| 巡检员 | 后台分配 | 巡检路线查看与打卡、工单接单与处理 |
| 维修人员 | 后台分配 | 工单接单、维修记录填报、沟通记录 |
| 财务人员 | 后台分配 | 合同审核、水电读数核对、费用结算 |
| 租户 | 自主注册（需审核） | 提交报修工单、查看合同与水电账单、沟通记录 |

### 2.2 功能模块

1. **登录与权限页**：Lucia Auth 登录、角色识别、待办跳转
2. **工作台首页**：角色待办汇总、超时预警横幅、快捷入口
3. **巡检路线管理**：路线规划、打卡记录、异常上报
4. **租户合同管理**：合同录入/续签/终止、审批流程
5. **水电读数核对**：抄表录入、用量比对、异常标记
6. **工单管理中心**：工单列表（超时高亮）、详情（沟通记录+复核意见）、状态流转
7. **审批中心**：审批意见录入、审批历史、状态追踪
8. **房屋档案**：楼宇/房间信息、租赁状态、设施清单
9. **报修响应趋势看板**：响应时长趋势、超时率、完成率、按角色/区域统计

## 3. 核心流程

**工单全生命周期流程**：租户提交报修 → 系统自动分配 → 维修人员接单 → 现场处理（记录沟通）→ 完工提交 → 超时检测与预警 → 复核意见录入 → 关闭归档。超时工单在列表中以红色边框+脉冲动画突出显示，确保不遗漏。

**审批流程**：合同/费用提交 → 对应角色审批 → 审批意见记录 → 通过/驳回 → 状态更新。所有审批意见全程留痕，支持历史追溯。

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深青蓝（#0F4C5C）为主色，搭配暖琥珀（#E36414）为强调色，传达专业稳重又不失活力的园区运营感
- **辅助色**：浅灰底（#F7F8FA）、白色卡片、超时红（#DC2626）
- **按钮风格**：圆角（8px）、主色实心按钮、次级描边按钮、危险操作红色按钮
- **字体**：思源黑体（Noto Sans SC）为主字体，数字使用 JetBrains Mono 等宽字体
- **布局风格**：左侧固定导航栏 + 顶部面包屑 + 主内容区卡片式布局
- **图标**：Lucide Icons 图标库，线性风格
- **动效**：超时工单卡片红色边框脉冲动画、页面切换淡入、卡片悬停微抬升

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 登录页 | 登录表单 | 居中卡片式表单、深青蓝渐变背景、Logo+标题、输入框带图标、主色登录按钮 |
| 工作台首页 | 待办汇总 | 四宫格统计卡片（图标+数字+标签）、超时预警横幅（红色背景脉冲）、快捷入口图标列表 |

| 租户合同 | 合同列表 | 表格布局、状态列彩色标签、搜索栏+筛选下拉在顶部 |

| 工单中心 | 工单详情 | 顶部状态条、左右分栏（信息+操作）、下方沟通记录气泡式对话、复核意见卡片 |
| 审批中心 | 待审批列表 | 左侧分类菜单、右侧审批卡片列表、数量角标 |

### 4.3 响应式设计

- 桌面优先（1920px/1440px/1280px）
- 平板适配（768px-1024px）：侧边栏折叠为图标模式、卡片从多列变双列
- 移动端适配（<768px）：侧边栏抽屉式、卡片单列、表格转卡片列表

### 4.4 无障碍设计

- 所有交互元素支持键盘操作
- 颜色对比度符合 WCAG AA 标准
- 超时预警除颜色外增加图标和文字标识
- 表单元素均有关联标签
