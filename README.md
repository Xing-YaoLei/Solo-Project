# 🏗️ 家装工地量房报价漏斗报表系统

基于 **Python Dash + Plotly + Pandas + PostgreSQL + Celery** 构建的家装工地全流程数据分析平台，用于拆解量房→报价→签单→施工→竣工各阶段漏斗数据，实现全链路数据追溯与可视化分析。

---

## ✨ 核心功能

### 📊 五大分析模块

| 模块 | 说明 |
|------|------|
| 🏠 **漏斗概览** | 量房→报价→签单→施工→竣工 全阶段转化漏斗，含项目数、转化率、报价金额 |
| 📊 **对账差异趋势** | 采购预算 vs 实际金额的月度趋势图，按分类差异排名，差异率条件高亮 |
| 📎 **合同附件构成** | 合同附件类型分布（饼图+柱状图），逐份合同附件明细清单 |
| 📝 **单据明细追溯** | 报价单 / 采购单 明细切换查看，采购单含报价关联字段可溯源 |
| ⚖️ **审批异常标注** | 审批状态分布 + 异常时间线（红点三角标注超时/驳回），异常判定规则 |
| 💰 **回款周期分析** | 各回款阶段平均周期/逾期天数，完整口径说明 |

### 🔐 权限与安全

- **七级角色体系**：管理员 / 经理 / 财务 / 监理 / 设计师 / 销售 / 只读用户
- **字段级脱敏**：非财务/经理/管理员角色看不到真实金额，显示为 `***`
- **视图权限控制**：各分析模块按角色权限独立授权
- **分享视图安全**：分享链接严格校验角色权限，即使拿到链接也无法绕过权限查看敏感数据
- **手动刷新权限**：仅指定角色可触发数据刷新任务

### 📥 数据接入（Celery 异步任务）

- **设计软件导出**：支持 JSON / Excel / CSV，自动解析并生成对应报价单条目
- **监理照片处理**：JPG/PNG 自动提取 EXIF 拍摄时间、生成缩略图、智能分类（量房/材料/进度/质量/验收）
- **采购单导入**：Excel/CSV 采购单明细，支持报价关联字段
- **全量刷新任务**：漏斗计算、对账差异、审批异常、回款周期统一计算

### 📤 导出功能

- **完整报表导出（Excel）**：含 11 个工作表，首页封面 + 回款周期口径专门说明页
- **回款周期口径**：在导出文件中明确说明：
  - 回款周期 = 实际回款日期 − 合同签订日期
  - 逾期天数 = 实际回款日期 − 计划回款日期
  - 各阶段定义、统计范围、异常情况处理规则

### ⏱️ 最近刷新时间显示

- **不在设置里隐藏**：最近刷新时间直接展示在**顶部导航栏右侧高亮位置**
- 支持**手动刷新按钮**，刷新时按钮变 loading 态并每 2 秒轮询任务状态
- 刷新完成显示 Toast 通知，包含处理记录条数

## 🚀 快速开始

### 环境要求

- Python 3.10+
- PostgreSQL 12+
- Redis 6+
- macOS / Linux

### 1. 安装依赖

```bash
cd MP0315
pip install -r requirements.txt
```

### 2. 配置环境变量

```bash
cp .env.example .env
# 编辑 .env，填入 PostgreSQL 与 Redis 连接信息
```

### 3. 启动服务依赖

确保 PostgreSQL 与 Redis 已运行：

```bash
# PostgreSQL
pg_ctl start  # 或 brew services start postgresql

# Redis
redis-server  # 或 brew services start redis
```

### 4. 初始化数据库

```bash
python init_db.py
```

### 5. （可选）填充演示数据

```bash
python seed_data.py
```

### 6. 启动 Celery Worker（异步任务）

```bash
python run_worker.py
```

### 7. 启动 Dash Web 应用

```bash
python run.py
```

应用将在 **http://localhost:8050** 启动。

## 🎨 核心图表详解

### 对账差异趋势
- 双 Y 轴：柱状图（预算 vs 实际）+ 折线图（差异率%）
- 滑块可选最近 1~24 个月范围
- 分类差异横向条形图（绿色=有结余，红色=超预算）
- 明细表：差异率 < −5% 红色高亮，> 5% 绿色高亮

### 审批异常标注
- 状态分布柱状图（按颜色区分通过/待/驳回/异常）
- 异常时间线：绿色圆点=正常，红色三角=异常，hover显示异常原因
- 明细表：整行红色底=异常，状态字段按状态着色

### 合同附件构成
- 左图：附件类型数量环形饼图
- 右图：各类附件总大小柱图
- 类型卡片：数量 + 文件大小统计

## ⚠️ 注意事项

1. **数据库编码**：PostgreSQL 推荐使用 `UTF-8` / `zh_CN.UTF-8`
2. **时区**：默认 `Asia/Shanghai`，请确认 PostgreSQL 与应用时区一致
3. **生产部署**：部署前务必修改 `.env` 中的 `SECRET_KEY`，并将 `DASH_DEBUG=false`
4. **Celery Worker**：生产环境建议使用系统级服务（systemd/supervisor）托管，单 worker 并发 `-c` 建议 2~4
5. **导出文件**：`exports/` 目录请定期清理，或配置 Nginx 做静态文件服务
6. **照片处理**：照片解析依赖 Pillow 读取 EXIF，如上传照片无 EXIF 则取上传时间

## 📌 回款周期口径（摘录，详见导出文件）

```
回款周期 = 实际回款日期 − 合同签订日期
逾期天数 = 实际回款日期 − 计划回款日期（提前为负）
5个回款阶段：定金(10%) → 开工款(30%) → 进度款(30%) → 竣工款(20%) → 质保金(10%)
注：质保金通常在竣工后1~2年支付，不计入回款周期均值。
```
