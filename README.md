# 康复中心患者分级风险监测系统

## 项目概述

本项目将患者分级从传统静态报表中拆分出来，构建独立的康复中心患者分级风险监测看板。采用现代化数据工程选型，支持实时监测、异常标注、多维度分析和数据导出功能。

## 工程选型

| 组件 | 技术 | 用途 |
|------|------|------|
| Web 框架 | **Streamlit** | 快速构建交互式数据看板 |
| 数据处理 | **Polars** | 高性能 DataFrame 数据处理 |
| 分析数据库 | **DuckDB** | 嵌入式列式 OLAP 数据库，支持复杂 SQL 查询 |
| 对象存储 | **MinIO** | 兼容 S3 的分布式对象存储（可选，用于大规模数据持久化） |
| 图表库 | **Plotly** | 交互式可视化图表 |

## 核心功能

### 1. 患者分级风险监测图
- 五等级风险分层（低危/中低危/中危/中高危/高危）
- 多色分级趋势曲线 + 总体平均参考线
- 支持按患者、诊断、风险等级筛选
- 平均/最高/最低三种聚合方式

### 2. 异常事件标注（看板刷新时自动标出）
- **💰 收费表延迟**：黄色阴影区 + 时间标注，显示延迟天数
- **📋 病历系统缺失**：统计缺失记录、待处理数量、涉及患者
- **🔧 康复设备口径变化**：紫色虚线标注校准版本变更日期
- 避免因系统延迟导致的趋势误判

### 3. 医保拒付影响分析
- 自动识别医保拒付集中时间段
- 标注拒付影响时间范围（开始/结束/持续天数）
- 统计拒付次数、金额、涉及患者数
- 给出趋势分析建议（对比拒付前后 7 天数据）

### 4. 训练完成率
- 附带完整计算规则（计划/完成定义、考核标准、不计入情况）
- 训练完成率趋势图（优秀线 90%、合格线 70%）
- 所有下载文件 ZIPPED 时自动附带 `TRAINING_COMPLETION_RULE.md`

### 5. 常用视图
- **📅 治疗日历**：热力图展示每日治疗类型分布、治疗明细列表
- **⚙️ 器械状态**：设备利用率热力图、当前设备状态卡片、校准/维护提醒
- **📋 护理日志**：各班次记录统计、生命体征明细、护士班次筛选

### 6. 复盘备注与异常点关联
- 异常点（红星标记）直接关联备注表单
- 支持按异常点添加审核人、复盘分析、后续处理措施
- 备注状态追踪（已解决/处理中）
- 历史备注查询

### 7. 数据下载中心
- 8 类数据独立下载标签页
- 所有下载自动附带训练完成率计算规则
- 支持 CSV / JSON 格式打包为 ZIP
- 包含风险趋势、患者明细、医保拒付、异常汇总、治疗、设备、护理、复盘等

## 快速开始

### 1. 安装依赖

```bash
cd MP0216
pip install -r requirements.txt
```

### 2. 配置环境变量（可选）

```bash
cp .env.example .env
# 编辑 .env，配置 MinIO 连接等参数
```

> 注意：如果不配置 MinIO，系统仍可正常运行（仅使用 DuckDB 本地存储）。

### 3. 初始化数据库（生成模拟数据）

```bash
python src/init_data.py
```

该脚本会自动：
- 创建 DuckDB 数据库文件 `data/rehab_center.duckdb`
- 生成 60 名患者、90 天风险数据
- 注入收费表延迟、病历缺失、设备口径变化、医保拒付等异常场景
- 生成治疗日历、设备状态、护理日志、复盘备注等关联数据

### 4. 启动 Streamlit 看板

```bash
streamlit run src/app.py
```

访问 `http://localhost:8501` 即可进入监测看板。

## 使用指引

### 侧边栏筛选
- **时间范围**：自定义查询起止日期（默认近 60 天）
- **风险等级**：多选筛选特定风险级别
- **诊断类型**：按诊断下拉筛选
- **患者选择**：精确选择单个或多个患者（留空=全部）
- **聚合方式**：趋势图使用平均/最高/最低值

### 顶部同步状态栏
- 收费表、病历、设备、医保四大系统的同步时效
- 延迟自动标红提醒
- 周期内异常事件概览（黄色/红色/蓝色警示）

### 风险监测图阅读
| 视觉元素 | 含义 | 处理建议 |
|----------|------|----------|
| 彩色曲线 | 各风险等级平均分走势 | 关注高危/中高危曲线 |
| 黑色虚线 | 全体患者平均参考线 | 判断整体趋势 |
| 黄色阴影 | 收费表延迟期 | 勿据此判断真实风险变化 |
| 紫色虚线 | 设备校准/固件升级 | 对比前后数据有效性 |
| 红色阴影 | 医保拒付高峰期 | 关注治疗执行率变化 |

### 单患者追踪
1. 在「单患者风险追踪」下拉选择患者
2. 查看柱状风险评分 + 折线训练完成率双轴图
3. 红星为异常点，悬停显示异常类型
4. 在「复盘备注」区为每个异常点添加备注

### 导出数据
1. 滚动至「数据下载中心」
2. 切换 8 个标签页选择需要导出的数据类型
3. 点击下载按钮（自动打包 ZIP，含训练完成率规则文档）

## 数据模型（核心表）

| 表名 | 说明 | 关键字段 |
|------|------|----------|
| `patients` | 患者基础档案 | patient_id, risk_level, risk_score |
| `patient_risk_daily` | 每日风险评分记录 | record_date, 6 项细分评分, 4 个异常标记 |
| `fee_table_sync_log` | 收费表同步日志 | delay_days, affected_records |
| `medical_record_gaps` | 病历缺失记录 | gap_type, resolved |
| `device_calibration_changes` | 设备校准变更 | old_version → new_version |
| `insurance_denials` | 医保拒付明细 | denial_code, denial_amount, appeal_result |
| `treatment_calendar` | 治疗日历 | treatment_type, status, device_id |
| `device_status` | 设备每日状态 | utilization_rate, calibration_due |
| `nursing_logs` | 护理日志 | 生命体征, shift, notes |
| `review_notes` | 复盘备注 | anomaly_type, review_note, resolved |

## 扩展建议

1. **接入真实数据源**：在 `data_service.py` 中替换模拟数据为 HIS/EMR 接口
2. **定时数据同步**：配合 Airflow 定时调用 DuckDB `INSERT` 脚本
3. **MinIO 归档**：使用 `storage.py` 将历史数据 Parquet 归档到对象存储
4. **风险模型升级**：在 `data_models.py` 中集成机器学习评分模型
5. **权限管控**：添加 Streamlit Authenticator 实现分级权限

## 技术支持

如有问题，请检查：
1. Python 版本 ≥ 3.10
2. DuckDB 数据库文件权限
3. 所有依赖是否完整安装（`pip check`）
