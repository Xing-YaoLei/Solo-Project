## 1. 产品概述

长租公寓维修派单排程台是为长租公寓运营方打造的维修派单调度管理平台，解决维修工单分配无序、路线规划低效、延误响应滞后等核心痛点。面向租客、管家、维修员、财务四类角色，实现从工单创建、路线排程、现场签到、轨迹回放到签收闭环的全流程数字化管控。

- 目标用户：长租公寓运营团队（管家调度、维修执行、财务结算）与租客（报修与评价）
- 核心价值：提升维修准时率，沉淀派单数据资产，缩短闭环周期

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 租客 | 手机号注册 | 提交报修、查看工单进度、签收确认、评价 |
| 管家 | 后台分配账号 | 工单分派、路线编排、延误处理、报表查看 |
| 维修员 | 后台分配账号 | 接单、签到、上传凭证、轨迹记录 |
| 财务 | 后台分配账号 | 费用审核、导出报表、成本分析 |

### 2.2 功能模块

1. **排程调度台（首页）**：路线计划看板、司机签到状态、实时地图概览、待办池入口
2. **路线计划页**：路线编排与优化、装载清单配置、派单操作
3. **轨迹回放页**：历史轨迹回放、签到节点回溯、异常标记
4. **工单管理页**：工单列表与详情、签收凭证留痕、补充材料、驳回重提
5. **待办池页**：延误工单汇总、重新分派、补充材料、驳回重提处理
6. **报表分析页**：准时率报表、日期维度下钻、负责人维度下钻、导出控制
7. **角色权限页**：角色入口配置、导出范围控制、敏感字段脱敏

## 3. 核心流程

### 3.1 维修派单主流程

租客提交报修 → 管家创建工单 → 管家编排路线并派单 → 维修员接单出发 → 维修员到达签到 → 执行维修并上传凭证 → 租客签收确认 → 工单完成归档

```mermaid
flowchart TD
    "租客提交报修" --> "管家创建工单"
    "管家创建工单" --> "管家编排路线"
    "管家编排路线" --> "派单至维修员"
    "派单至维修员" --> "维修员接单出发"
    "维修员接单出发" --> "到达签到"
    "到达签到" --> "执行维修"
    "执行维修" --> "上传凭证"
    "上传凭证" --> "租客签收"
    "租客签收" --> "工单归档"
    "执行维修" --> "路线延误?"
    "路线延误?" --> "是" --> "自动进入待办池"
    "自动进入待办池" --> "管家处理延误"
    "管家处理延误" --> "重新分派"
    "管家处理延误" --> "补充材料"
    "管家处理延误" --> "驳回重提"
    "重新分派" --> "派单至维修员"
    "驳回重提" --> "维修员修改"
    "维修员修改" --> "上传凭证"
```

### 3.2 延误处理流程

路线延误自动触发 → 工单进入待办池 → 管家选择处理方式 → (重新分派 / 补充材料 / 驳回重提) → 流程继续或重启

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深蓝灰 (#1B2A4A) + 琥珀色强调 (#E8A838)，传达专业调度与高效运营感
- **辅助色**：状态色 — 进行中(翠绿 #2ECC71)、延误(警示红 #E74C3C)、待处理(天蓝 #3498DB)、已完成(石墨灰 #7F8C8D)
- **按钮风格**：微圆角(6px)带细微阴影，主操作实色填充，次操作描边
- **字体**：标题使用 DM Sans (粗体 600/700)，正文使用 Noto Sans SC (常规 400/500)，数据数字使用 JetBrains Mono
- **布局**：左侧窄导航 + 顶部操作栏 + 主内容区，操作区与配置面板左右分栏
- **图标**：线性风格 (Lucide Icons)，与整体专业简洁调性一致
