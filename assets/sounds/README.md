# 音效资源目录

请在此目录下放置以下音效文件：

## 所需文件

| 文件名 | 用途 | 建议时长 | 建议格式 |
|--------|------|----------|----------|
| `click.wav` | 按钮点击音效 | 0.1-0.2秒 | WAV 16-bit |
| `correct.wav` | 回答正确音效 | 0.4-0.6秒 | WAV 16-bit |
| `wrong.wav` | 回答错误音效 | 0.4-0.6秒 | WAV 16-bit |
| `complete.wav` | 关卡完成音效 | 0.8-1.2秒 | WAV 16-bit |

## 技术要求

- 采样率：44100 Hz 或 48000 Hz
- 位深度：16-bit
- 声道：单声道或立体声
- 音量：标准化到 -1dB 到 -3dB

## 说明

如果缺少音效文件，游戏仍然可以正常运行，只是不会播放音效。
AudioManager 会自动检测文件是否存在。
