# 美业门店顾客回访调度解谜游戏

基于 Godot 4 的美业门店顾客回访调度解谜游戏，用于练习顾客回访判断和门店运营决策。

## 游戏特色

- **可拖拽充值流水系统** - 将充值卡拖拽到顾客身上提升满意度和耐心
- **动态评价标签** - 完成项目后动态生成评价标签
- **计时任务与项目卡项** - 三个工位同时处理不同项目，限时完成
- **耗材异常突发事件** - 随机出现耗材异常，提前视觉提示，手动解除获奖励
- **复盘统计** - 消课率、完成时间、玩家卡点分析
- **难度曲线可调** - 简单/普通/困难三种难度
- **道具系统** - 加速、补货、魅力、时间冻结四种道具
- **成就系统** - 多种成就激励玩家
- **失败回放** - 保留最近三次失败回放，支持对比分析

## 游戏玩法

### 基本操作
1. **点击顾客** - 将顾客分配到空闲工位开始项目
2. **拖拽充值卡** - 从右侧充值流水区拖拽充值卡到顾客身上
3. **点击警告** - 耗材异常警告出现时点击解除
4. **使用道具** - 点击右侧道具栏的道具按钮

### 游戏目标
- 在 180 秒内尽可能多地服务顾客完成项目
- 保持高连击获得更多分数
- 管理耗材库存，及时处理异常事件

### 顾客类型
- 👩 洗剪吹 - 基础项目，速度快
- 👩‍🦰 洗吹造型 - 中等项目
- 👩‍🦳 染发 - 高级项目，分数高耗时长
- 👩‍🦱 烫发 - 高级项目，分数最高耗时最长
- 👧 护理 - 保养项目

### 道具说明
- ⚡ 加速药水 - 项目进度加速 50%
- 📦 紧急补货 - 所有耗材补充 30 点
- ✨ 魅力加成 - 所有顾客耐心恢复
- ❄️ 时间冻结 - 时间流速减缓 70%

### 成就列表
- 初次见面 - 服务第一位顾客
- 得心应手 - 达成 5 连击
- 游刃有余 - 达成 10 连击
- 应急专家 - 成功处理 5 次耗材异常
- 业绩冠军 - 单局得分超过 5000

## 难度设置

策划可以通过修改 `scripts/autoload/difficulty_config.gd` 调整：
- 顾客刷新间隔
- 项目时间倍率
- 耗材消耗倍率
- 异常出现概率
- 异常警告时间
- 连击加成倍率
- 道具冷却倍率
- 关卡配置
