## 1. 产品概述

高校教务成绩复核风险监测图用于拆解高校教务的成绩复核数据，帮助教务管理人员、院系领导与导师快速识别成绩复核流程中的异常与风险点。系统接入教务库、学生申请表和一卡通明细数据，通过可视化图表呈现学生名单趋势、成绩单构成、申请材料明细以及导师名额异常标注，并支持角色权限控制、分享链接与导出功能。

- 目标用户：高校教务处管理人员、院系领导、导师、学生
- 核心价值：提升成绩复核流程的透明度与风险识别效率，减少人为疏漏

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 教务管理员 | 学校统一认证 | 查看全部数据、管理角色与分享链接、导出报告 |
| 院系领导 | 学校统一认证 | 查看本院系数据、导出本院系报告 |
| 导师 | 学校统一认证 | 查看本导师名下学生数据、标注异常 |
| 学生 | 学校统一认证 | 查看本人成绩复核状态与申请进度 |

### 2.2 功能模块

1. **监测总览页**：核心仪表盘，展示四大图表模块与最近刷新时间，支持全局筛选
2. **学生名单趋势页**：折线图呈现各时间段成绩复核申请人数变化趋势
3. **成绩单构成页**：饼图/柱状图展示成绩等级分布与复核前后对比
4. **申请材料明细页**：表格展示申请材料提交状态与一卡通追溯明细
5. **导师名额异常页**：散点图/热力图标注导师名下学生名额异常情况
6. **分享与导出页**：生成角色范围限定分享链接，导出含教室利用率口径说明的报告

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 监测总览 | 刷新时间指示器 | 显示数据最近刷新时间，支持手动刷新 |

| 监测总览 | 成绩单构成卡片 | 饼图展示成绩等级占比，柱状图展示复核前后变化 |

| 监测总览 | 导师名额异常卡片 | 散点图标注导师名额偏差，红色标记异常导师 |

## 3. 核心流程

用户登录后进入监测总览页，根据角色权限看到对应范围的数据卡片。教务管理员可查看全部四个图表模块，院系领导看到本院系数据，导师看到本人名下学生数据，学生只看本人状态。用户可点击卡片进入详情页查看更丰富的图表与筛选条件。通过分享功能生成链接，接收方打开后根据其角色看到对应数据范围。导出报告时自动附加教室利用率口径说明。

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深靛蓝 (#1B2A4A) 搭配琥珀色 (#F59E0B) 作为警示强调色
- 辅助色：石板灰 (#64748B) 用于次级信息，翡翠绿 (#10B981) 表示正常状态，珊瑚红 (#EF4444) 标记异常
- 按钮风格：圆角 8px，主按钮实心填充，次按钮描边风格
- 字体：思源黑体 (Noto Sans SC) 作为正文，DM Sans 作为数字与英文展示字体
- 布局风格：左侧固定导航栏 + 右侧内容区域，卡片式布局
- 图标风格：线性图标 (Lucide Icons)

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 监测总览 | 顶部信息栏 | 深靛蓝背景，白色标题，右侧刷新时间戳与手动刷新按钮 |
| 监测总览 | 学生名单趋势卡片 | 白色卡片，折线图，右上角同比环比标签 |
| 监测总览 | 成绩单构成卡片 | 白色卡片，左侧饼图右侧柱状图并排 |
| 监测总览 | 申请材料明细卡片 | 白色卡片，紧凑表格，状态用彩色标签表示 |
| 监测总览 | 导师名额异常卡片 | 白色卡片，散点图，异常点红色脉冲动画 |
| 详情页 | 筛选面板 | 左侧折叠式筛选器，下拉选择院系/专业/学期 |
| 详情页 | 图表区域 | 大尺寸图表，鼠标悬浮显示详细数据提示框 |
| 分享与导出 | 分享面板 | 模态弹窗，角色选择下拉，一键复制链接 |

### 4.3 响应式设计

- 桌面优先设计，最小宽度 1280px
- 平板端 (768-1279px)：导航栏折叠为汉堡菜单，卡片单列排列
- 移动端 (<768px)：仅展示关键指标与简化图表，详情页隐藏高级筛选
