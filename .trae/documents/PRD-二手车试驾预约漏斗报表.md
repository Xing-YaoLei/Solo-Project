## 1. 产品概述
二手车门店试驾预约漏斗报表系统，用于追踪二手车门店的试驾预约全流程管理与数据分析。

- 核心目标：通过多数据源整合（金融审批、CRM、检测仪），实现试驾预约转化漏斗可视化，辅助管理层决策和一线销售提升转化效率
- 目标用户：门店管理层（看总览数据）、一线销售人员（查看个人负责线索明细）

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 管理层 | 系统内置账号 | 查看全店总览报表、所有门店对比、数据分析、批次回查导入记录 |
| 一线销售 | 系统内置账号 | 查看本人负责线索明细、试驾爽约注释、个人转化数据 |

### 2.2 功能模块
1. **总览仪表盘**：核心指标卡片、转化漏斗图、试驾记录排行
2. **数据分析区**：预约时段分布、试驾反馈漏斗、客户线索变化趋势
3. **线索转化明细**：线索列表、试驾状态追踪
4. **数据导入管理**：批次导入、回查、数据合并（金融审批→CRM→检测仪）
5. **爽约注释**：试驾爽约备注

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|----------|
| 总览仪表盘 | KPI指标卡 | 展示总预约数、到店数、试驾完成数、转化率 |
| 总览仪表盘 | 转化漏斗 | 线索→预约→到店→试驾→成交漏斗可视化 |
| 总览仪表盘 | 试驾记录排行 | 销售人员试驾量排行、车型试驾排行 |
| 数据分析 | 预约时段分布 | 按小时/天的预约时段热力图 |
| 数据分析 | 试驾反馈漏斗 | 预约→到店→试驾完成→反馈满意度漏斗 |
| 数据分析 | 客户线索变化 | 线索量、试驾量变化趋势图 |
| 线索明细 | 线索列表 | 按销售/筛选线索列表，支持状态筛选、负责人筛选 |
| 线索明细 | 爽约注释 | 对爽约记录添加注释说明 |
| 数据导入 | 批次管理 | 导入批次列表、批次详情回查 |
| 数据导入 | 数据源合并 | 金融审批表优先处理，合并CRM、检测仪数据 |

## 3. 核心流程
用户登录系统后，根据角色权限展示不同视图：管理层查看全店总览，一线销售查看个人负责线索。数据通过批次导入金融审批表为基础，依次合并CRM和检测仪数据，形成完整的试驾预约数据链。

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：深海军蓝 (#0F172A）搭配科技感青色 (#22D3EE)
- 辅助色：琥珀色 (#F59E0B（预警）、翠绿 (#10B981（成功）、玫红 (#EF4444（异常）
- 字体：系统采用专业商务风格
- 按钮风格：极简圆角按钮，带微阴影
- 布局风格：卡片式布局，顶部导航栏 + 侧边导航
- 图标风格：线性简洁图标

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI 元素 |
|---------|---------|----------|
| 总览仪表盘 | KPI卡片 | 深色卡片，数字大字号，趋势小标签 |
| 总览仪表盘 | 漏斗图 | ECharts 漏斗图，渐变色填充 |
| 总览仪表盘 | 排行列表 | 条形图+排名徽章 |
| 数据分析 | 时段分布 | 热力图/柱状图 |
| 数据分析 | 反馈漏斗 | 多层漏斗 |
| 数据分析 | 趋势图 | 折线图+区域填充 |
| 线索明细 | 数据表格 | 可筛选、可排序表格 |
| 线索明细 | 注释弹窗 | 模态框，多行文本输入 |
| 数据导入 | 批次列表 | 时间线式列表 |
| 数据导入 | 合并进度 | 进度条展示 |

### 4.3 响应式
桌面端优先设计，支持平板自适应，移动端优化表格滚动和筛选折叠。

### 4.4 动效设计
- 页面加载：卡片渐入动画，延迟100ms交错出现
- 图表：数据加载动画，数字滚动动效
- 交互：按钮悬停微放大，表格行悬停高亮
