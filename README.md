# 🎫 票务经营模拟大师

一款活动票务演出票务经营模拟游戏

## 游戏简介

这是一款专业的活动票务、演出票务经营模拟游戏，玩家需要在倒计时内处理各种类型的购票订单，
根据票种规则选择正确的座位，锻炼快速判断力。

## 游戏特色

### 🎮 核心玩法
- **倒计时挑战**: 在限定时间内完成目标订单数量
- **多票种规则**: VIP票、高级票、标准票、学生票、团体票，各有购买限制
- **座位图管理**: 可视化座位选择，按区域和票种匹配
- **订单验证**: 检查身份证、学生证、年龄、团体人数等规则
- **即时反馈**: 速度、准确度、连击数实时统计

### 📊 结算页面
- **速度评分**: 每分钟处理订单数计算
- **错误次数**: 错误次数统计与显示
- **连续正确**: 最高连击数奖励
- **综合效率**: 多维度综合评分
- **星级评价**: 根据效率给予1-3星评价

### ⚙️ 设置选项
- **声音开关**: 音效总开关
- **音乐音量**: 背景音乐独立调节
- **音效音量**: 音效独立调节
- **震动反馈**: 可关闭适合安静场合
- **动画强度**: 关/低/中/高四档调节，支持工作间隙安静练习

### 🔄 失败快速重开
- 失败后**一键重开**当前关卡
- 复盘页面比较不同关卡**核销效率**
- 历史记录柱状图对比

### ⌨️ 操作方式
**触屏操作**:
- 点击座位选择/取消
- 点击按钮确认/拒绝订单

**键盘快捷键**:
- `[空格]` - 确认当前订单
- `[R]` - 拒绝无效订单
- `[S]` - 自动推荐座位
- `[C]` - 清空选择
- `[ESC]` - 暂停游戏

## 启动方式

### 开发模式
1. 安装 Cocos Dashboard
2. 使用 Cocos Creator 3.8+ 打开项目
3. 选择 `main-menu` 场景作为启动场景
4. 点击运行按钮启动游戏

### Web构建
```bash
# 安装依赖
npm install

# 构建项目
npm run build
```

## 游戏攻略提示

1. **先看订单，再选座**: 先仔细阅读订单的证件要求，再去座位图选座
2. **学生票需学生证**: 学生票必须同时有学生证且年龄在12-26岁
3. **团体票人数要够**: 团体票最少10人起购
4. **VIP需身份证**: VIP票必须出示身份证
5. **连续正确有奖励**: 保持连击可获得额外分数加成
6. **无效订单要拒绝**: 证件不全的订单应该果断拒绝
7. **善用推荐功能**: 拿不准时按[S]让系统推荐
8. **快速清空**: 选错按[C]快速清空选择
