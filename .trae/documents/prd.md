## 1. 产品概述

青少年培训教材发放跟进台——面向培训机构的教材分发与学习进度管控平台，解决教材发放后难以追踪学员学习状态、进度滞后风险不可见、沟通记录零散等核心问题。目标用户为培训机构教务人员、课程讲师和管理层。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 教务专员 | 管理员分配账号 | 教材发放、进度录入、沟通记录、提醒管理 |
| 课程讲师 | 管理员分配账号 | 查看所授课程进度、录入成绩反馈、复核结论 |
| 管理层 | 管理员分配账号 | 查看完成率趋势、风险概览、过滤无关记录 |

### 2.2 功能模块

1. **教材发放工作台**：按日常处理节奏排列的待办入口（待发放→待跟进→待复核→已完成），题目标签快速定位，批量发放操作
2. **学习进度跟踪**：进度百分比可视化、成绩反馈录入与核对、课程章节完成标记
3. **风险预警列表**：进度落后学员风险等级（高/中/低）直接可见，一键查看处理详情（沟通记录+复核结论）
4. **提醒规则管理**：自定义提醒触发条件、提醒方式与频次，自动生成待办
5. **管理层看板**：完成率趋势图、风险分布统计、无关记录过滤

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 教材发放工作台 | 待办入口区 | 按日常处理节奏排列：待发放、待跟进、待复核、已完成四个看板卡片，显示各状态数量 |
| 教材发放工作台 | 记录列表 | 题目标签置顶显示，支持按标签筛选；列表行直接显示风险等级标签（红/橙/黄） |

| 管理层看板 | 记录过滤 | 一键过滤无关记录（已结业、已转出等），聚焦有效数据 |

## 3. 核心流程

教务专员日常操作流程：登录后进入工作台，按待办节奏处理任务——先处理待发放教材（选择学员和章节，确认发放），随后跟进待跟进学员（查看进度、录入沟通记录），对已完成阶段性学习的学员进行成绩复核。当系统检测到进度落后时，自动触发提醒规则，在风险预警列表中标记风险等级。管理层在看板查看整体完成率趋势和风险分布。

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深靛蓝（#1B3A5C）+ 活力橙（#F28C28）作为强调色
- 辅助色：浅灰背景（#F5F6FA），风险等级三色（红#E74C3C/橙#F39C12/黄#F1C40F）
- 按钮风格：圆角8px，主按钮实色填充，次按钮描边
- 字体：标题使用思源黑体/Noto Sans SC Bold，正文使用 Noto Sans SC Regular
- 布局风格：左侧导航+顶部操作栏，卡片式内容区
- 图标风格：线性图标，统一2px线宽

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 教材发放工作台 | 待办入口区 | 四张统计卡片横排，各显示状态图标+数字+环比变化 |
| 教材发放工作台 | 记录列表 | Naive UI DataTable，题目标签用NTag组件，风险等级用NBadge徽标 |
| 教材发放工作台 | 快速发放弹窗 | NModal弹窗，NTransfer穿梭框选择学员，NSelect选择教材 |
| 学习进度页 | 进度概览 | NProgress进度条+步骤条标记章节完成状态 |
| 风险预警页 | 风险列表 | 列表行首显示三色圆点标识风险等级，点击展开NDrawer |
| 风险预警页 | 处理详情抽屉 | NDrawer抽屉，NTimeline展示沟通记录，NDescriptions展示复核结论 |
| 提醒规则页 | 规则配置 | NForm表单，NInputNumber设置阈值，NRadioGroup选择方式 |
| 管理层看板 | 完成率趋势 | 折线图（ECharts），月份X轴，计划/实际双线 |
| 管理层看板 | 风险分布 | 饼图+柱状图组合，支持按课程维度切换 |

### 4.3 响应式设计

- 桌面优先设计，最低支持1280px宽度
- 平板端侧边导航折叠为图标模式
- 移动端仅保留核心列表和操作，图表降级为数据表格

### 4.4 动效设计

- 页面切换：淡入淡出150ms
- 列表加载：骨架屏占位
- 风险标签：轻微脉冲动画提示关注
- 卡片悬停：微妙上浮+阴影加深
