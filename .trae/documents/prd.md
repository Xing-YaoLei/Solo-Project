# 连锁咖啡会员储值风险监测系统 - 产品需求文档 (PRD)

## 1. 产品概述

### 1.1 项目背景
连锁咖啡品牌面临会员储值资金安全风险，需要建立一套完整的监测体系，实时追踪会员储值账户变动、续费率、权益核销等关键指标，提前识别异常风险，保障资金安全。

### 1.2 产品目标
- 建立会员储值全生命周期数据监测体系
- 实现管理层总览与一线人员明细分层权限
- 支持多维度数据分析与风险预警
- 提供数据导入批次可追溯能力

### 1.3 目标用户
| 用户角色 | 权限范围 | 核心需求 |
|---------|---------|---------|
| 管理层 | 全门店数据可见 | 储值总览、风险预警、跨店对比 |
| 一线人员（店长/店员） | 仅负责门店数据 | 本店续费率明细、会员跟进 |

---

## 2. 功能需求

### 2.1 数据导入与指标加工
#### 2.1.1 数据源导入
- **会员小票数据**：会员消费小票明细（会员ID、门店、消费金额、储值抵扣、积分变动等）
- **库存表数据**：商品库存变动与成本数据
- **POS流水数据**：收银台全量交易流水

#### 2.1.2 指标加工流程
```
会员小票 → 清洗标准化 → 关联库存表（商品成本核算） → 合并POS流水（交易完整性校验） → 指标计算
```

#### 2.1.3 批次管理
- 每次导入生成唯一批次号
- 批次状态追踪（待处理/处理中/已完成/失败）
- 支持按批次回查原始数据与加工结果
- 导入错误日志与异常数据标记

### 2.2 权益管理与注释
#### 2.2.1 权益过期监测
- 储值余额有效期追踪
- 优惠券/权益券过期预警
- 即将过期会员列表（7天/30天/90天）

#### 2.2.2 注释功能
- 针对权益过期会员可添加跟进注释
- 注释记录（操作人、时间、内容）
- 注释历史可追溯

### 2.3 权限体系
#### 2.3.1 管理层视图
- 全品牌储值总览仪表盘
- 跨门店对比分析
- 风险预警总览
- 全量数据分析

#### 2.3.2 一线人员视图
- 仅可见负责门店数据
- 本店会员续费率明细
- 本店会员跟进列表
- 本店核销与退款明细

---

## 3. 分析区功能

### 3.1 账户流水分布
- 维度：按金额区间、时间、门店、会员等级
- 图表：柱状图 + 堆叠面积图
- 指标：充值笔数、消费笔数、净流转入/出

### 3.2 等级变化漏斗
- 漏斗层级：注册 → 首次储值 → 活跃 → 高价值 → 流失
- 转化率追踪
- 时间范围可切换

### 3.3 核销记录排行
- 按门店、商品、会员等级排行
- Top N 排行
- 核销金额与核销次数双维度

### 3.4 退款原因变化
- 退款原因分类统计
- 时间趋势折线图
- 门店维度对比

---

## 4. 非功能需求

### 4.1 性能要求
- 仪表盘首屏加载 < 3s
- 图表渲染 < 1s
- 数据导入处理 10万条记录 < 5min

### 4.2 安全要求
- 基于角色的访问控制（RBAC）
- 敏感数据加密存储
- 操作日志审计

### 4.3 可扩展性
- 支持后续接入更多数据源
- 指标计算引擎可扩展

---
